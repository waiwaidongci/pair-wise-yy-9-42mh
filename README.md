# 古法蓝晒底片闭环台

每张底片按编号唯一建档，依次经过 **涂布 → 晾干 → 曝光 → 冲洗 → 复晒 → 入盒** 的闭环流程。

规则：

- 跳步或重复提交无效，仅保留首次成功记录
- 冲洗前必须记录水源，否则不得继续
- 复晒发现缺陷只能转入修补，修补确认后才可入盒
- 已交付底片更换盒位会立即失效并回到待入盒，旧履历归档可查但不计入当前统计
- 同一底片并发提交仅一次生效；筛选、统计与刷新后保持一致

运行：

```bash
npm start
```

访问 `http://localhost:3040`。数据保存在 `data/cyanotype-negative-room.json`。
