# 古法蓝晒底片闭环台

运行：

```bash
npm start
```

访问`http://localhost:3040`。数据保存在`data/cyanotype-negative-room.json`。

## 闭环规则

- 每张底片编号唯一，依次经过：涂布 → 晾干 → 曝光 → 冲洗 → 复晒 → 入盒。
- 跳步或重复提交会被拒绝，只保留首次成功记录。
- 冲洗前必须记录水源，否则不得继续。
- 复晒发现缺陷时只能进入修补，修补确认后才可入盒。
- 已交付底片更换盒位会立即失效并回到待入盒，旧履历归档可查、不计入当前统计。
- 同一底片的并发提交仅一次生效；筛选、统计与刷新后数据一致。
